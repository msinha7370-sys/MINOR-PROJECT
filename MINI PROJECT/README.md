# Smart Tourism Management - Mini Project (Demo)

Run:
1. python -m venv venv
2. source venv/bin/activate   # windows: venv\Scripts\activate
3. pip install -r requirements.txt
4. python init_db.py
5. python app.py
6. Open http://127.0.0.1:5000

Demo tips:
- Use the Admin page to manually change crowd levels.
- Use the curl command to simulate IoT sensor POST to /api/sensor.
- Enter tags in home page (e.g., "nature, food") to see personalized recommendations.
